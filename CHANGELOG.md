# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-26

### Добавлено
- Вкладка **«Устройства»**:
  - BLE-сканирование с уровнем сигнала (RSSI) и фильтром разрешений для Android 6–16;
  - подключение к **BLE Serial** устройствам: HM-10 / HC-08 / CC2541 (`FFE0`/`FFE1`),
    Nordic UART Service (`6E400001-3`), автоматический поиск характеристики write+notify;
  - подключение к **USB UART** (через OTG): WCH CH340/CH341, Silicon Labs CP210x,
    FTDI FT232R/FT231X/FT2232H/FT4232H, Prolific PL2303, Arduino, Teensy,
    STM32 VCP, SEGGER J-Link — с автоопределением чипа по VID/PID;
  - переключатель **«Только Serial-устройства»** — фильтр, который отсеивает
    устройства, непригодные для serial-обмена;
  - кнопка отключения устройства.
- Вкладка **«TCP сервер»**:
  - локальный TCP-сервер на `0.0.0.0:8080` (порт настраиваемый);
  - двусторонний проброс данных: устройство → broadcast всем клиентам,
    клиент → устройство;
  - поддержка нескольких TCP-клиентов одновременно;
  - счётчики переданных байт и журнал событий.
- Android-конфигурация: разрешения BLE (включая `neverForLocation`),
  INTERNET, USB Host + `device_filter.xml` со списком чипов UART.
- Тёмная и светлая темы (Material 3).

### Исправлено
- Запрос разрешения на местоположение больше не выполняется на Android 12+
  (для BLE-скана используется `BLUETOOTH_SCAN` с флагом `neverForLocation`).
- Иконка приложения: симметричные стрелки по центру.
